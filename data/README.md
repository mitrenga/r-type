# data/ — what is extracted from the original (**committed**)

| file | made by | what it holds |
|---|---|---|
| `screen.json` | `tools/mkscreen.py --at 300` | **a frame of level 1 as the chip saw it**: VIC bank 3 (`$C000`–`$FFFF`, 16 KB including the RAM under the I/O — Screen RAM, three character sets, sprites) at the top of the playfield (`$0D04`, raster 48), Color RAM, registers `$D000`–`$D02E`, and **every store** into the VIC registers, Screen RAM, sprite pointers and Color RAM during the frame with raster, cycle and value (40 stores). `app/screenLoader.js` composes it; `tools/matchscreen.mjs` measures it against the VICE frame (64 000 / 0). The `screenshot` field points into `build/` (outside git, `mkscreen.py` makes it again) |

| `levels.json` | `tools/dumplevels.py` | **8 levels**: the block placement script and the blocks (the 19 × 512 map is not built here — `$162F` in `app/levelScroll.js` builds it), colour and property of each character (`$8CAC`, `$8D6C`), end pointer, checkpoint, init and hook of the level, playfield colours; level 3's 23 × 79 map and the two window scripts; level 2's colour table switch (`$943B`). Measured by `tools/matchlevels.mjs` (8 levels, 783 samples, 1 407 655 / 0) |
| `charsets.json` | `tools/dumpcharset.py` | **character sets**: upper playfield `$C000` per level (`$86AC` from `G` + 64 glyphs `$8C53` from side A), lower playfield `$E000` (`S`), panel `$C800` (`$9D53`); after the level init (clearing and the star seeds `$AF`–`$BF` in levels 1 and 4); which glyphs are rewritten at run time (stars, the animations of levels 2 and 6). Measured by `tools/matchcharset.mjs` (42 824 / 0) |
| `sprites.json` | `tools/dumpsprites.py` | **sprites**: 63 blocks `$40`–`$7F` under the I/O (the ship and weapons, side A) and each level's enemy blocks from `$E800` (`S`), named by their place in the code. Measured by `tools/matchsprites.mjs` (49 696 / 0) |
| `waves.json` | `tools/dumpwaves.py` | **waves**: the (column, type) pairs of each level and 14 tables of 62 types from `M` (with the address where the spawner `$4FA8` reads them) — meaning is M4 |
| `texts.json` | `tools/dumptexts.py` | **texts and the panel**: panel `$8B73` with colours `$5F61` and the init's stores, READY / GAME OVER (`$0C5B`…), PLEASE REWIND TAPE (`$5F0D`, the panel set's alphabet), title screen (`$844E`…), the hidden credits text (`$36A9`) |
| `ship.json` | `tools/dumpship.py` | **tables and start values of the ship code** at the original's addresses (63 regions: Force, bits, explosions, shots, lasers, beam, missiles, items, score, sounds, patched operands; from M5 the checkpoints `$0B64`, the READY texts `$0C5B` and the texts after GAME OVER `$5F0D`) and the constants of the rules (lives, a life per 100 000, the READY countdown and its colours, 400 frames of sequence, two players switched off, the ending `E`); `app/ship.js` and `app/gameRules.js` copy them into `ram`. Measured by `tools/matchship.mjs` (37 064 000 / 0) and `tools/matchrules.mjs` |
| `enemies.json` | `tools/dumpenemies.py` | **the memory of the enemy and boss code at the original's addresses**: core `$4F00`–`$5FBB` (spawner, state machine, boss, tables and patched operands), each level's `M` `$7AC0`–`$86AB` (the end object's record, type tables, waves, boss tables and boss step) and `G` `$8E6C`–`$99FF` (the hook of the chain, animations, variables); `app/enemies.js` and `app/levelCode.js` keep their variables in it, `tools/matchenemies.mjs` compares all of it. Per level, `variables` says what in the code is a variable |
| `music.json` | `tools/dumpmusic.py` | **the SID player and the song of each level** from file `M` at the original's addresses (`$637F`–`$7ABF`: the player's variables with their values from the tape, code `$6476`–`$6D3F` — the same in all eight levels, rewritten in `app/sidPlayer.js` — with the frequency and waveform tables, and from `$6D40` the song: 22 relative pointers to the order lists, transposes, tune table, tracks, instruments and wave programs); for each level the tune table 0–3 spelled out (boss, GAME OVER, sequence, level); **`title`** = the title song from side A at its own addresses `$71D0`–`$7FFF` (the player `$8000` is the level player moved by `$490`, same code and tables as level 1; the song's order lists point at the tracks absolutely, so it is not moved; table `$71D0`, tune 2) — ABOUT plays it once. `app/ship.js` copies it into `ram` with every level load; measured by `tools/matchsound.mjs` |
| `picture.json` | `tools/dumppicture.py` | **the loading picture** of side A (file `P`, `$7000`–`$985E`): a multicolour bitmap of 8 000 B (shown at `$E000`), Screen RAM 1 000 B (`$CC00`), Color RAM 1 000 B (`$D800`), background and border black, the registers and the display code (`$97D0`, waits for space at `$9849`). Drawn by `app/loadingPictureEntity.js` (menu LOADING PICTURE) |
| `title.json` | `tools/dumptitle.py` | **the title logo**: its own set `$85CB` (6 pages, shown at `$C000`), 7 × 39 screen codes from `$84A6` (columns 1–39, `$80E6`), Color RAM `$09`, `$D022` = 3, `$D023` = 11, multicolour; the sprite `$8494` that flies over the logo. Drawn by `MenuModel.showLogo` at the top of the menu; the whole title screen with texts and music is M7 |
| `global.json` | `tools/dumpglobal.py` | **the core's per-level tables** (`$139A`–`$13E2`, `$0B64`, `$207C`), row addresses, the level 3 scripts, the two-player state, the scroll and VIC constants with their place in the code |

The application gets them all at once at start-up (`db/appData.php`, `appData.db`, section = file) and the models read them from localStorage (`loadDataFile`); `waves.json` is not sent — the game launches the waves from the enemies' memory, the file is for the tools. **The files hold neither notes nor provenance** (`source`, `note`, descriptions of variables and places in the code): `rtlib.save_json` leaves them out when writing (`strip_notes`), because the game reads none of them and in localStorage they only take up room (operator 2026-10-25).

The data is from the Electric Dreams tape (the reference, `../sources/tape/README.md`);
it belongs to the holders of the original's rights, the remake is non-commercial (`../ZADANI.md` §0).
